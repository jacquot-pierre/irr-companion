First release of **IRR Companion**, a small portable companion app for Incursion Red River.

**AI presets**
- The game's difficulties (Recruit, Regular, Veteran, Elite) and simulation levels built in.
- Editor with the same 35 settings as the in-game AI menu, custom simulation ranges, reference values.
- Side-by-side comparison of two presets with highlighted differences.
- Share codes: copy a code to paste in the game, import codes from the game or other players.
- Presets are saved in the app only (`%APPDATA%\IRR Companion`), never in the game files.

**Console commands**
- 151 `irr.*` console commands by category, with an *Essentials* list for everyday use.
- A control for every argument (switches, lists, sliders, map + weather picker, item picker with 840 items).
- One-click **COPY** of the full command, and favorites with your own names.

Game data: build of 2026-11-06. Not yet confirmed in game: the first weather number of `irr.World.SetWeather` (assumed 1).
