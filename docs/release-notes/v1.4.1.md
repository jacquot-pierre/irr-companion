A fix for **Add item (legacy)** in the COMMANDS tab, and a **web version** of the app.

**Add item (legacy)** (`irr.Item.Add`)
- The item list now shows the rows of the game's vendor table, the names this command needs. They often differ
  from the item names used by Give item and Spawn item (e.g. `HK_MP5_9x19_30rnd_magazine` for the MP5
  magazine). Before, the box suggested the item names, which this command does not always accept.
- **List items** (`irr.Item.List`): reminds you to run *List item categories* first for the exact names.

**Web version**
- Every tab of the app also runs in the browser, on a PC or a phone, nothing to install:
  https://irr-companion.seigneurguerande.fr
- **EXPORT** / **IMPORT** in each tab move your presets, favorites, weapon builds and hideout progress between
  the web version and this app. Share codes are the same in both.

Your presets, favorites, weapon builds and hideout progress are kept. Game data: version 1.4.0.1 (2026-11-06).
Game icons and minimaps are the developers' artwork, shown for reference (see the README).
