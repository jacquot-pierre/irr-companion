A new **WEAPONS** tab to build a weapon and get the `additem` line that gives it, and a simpler presets editor.

**Weapon builder** (new tab)
- Pick a base weapon (49, by class) and a part for each slot. Each slot only offers the parts the game accepts
  in it - the same data as the gunsmith - so you cannot put a part on a weapon that does not take it.
- Parts of parts: rails, grips and sights on a handguard, a muzzle on a barrel... show up under their part.
  Changing a part or the base weapon keeps the parts that still fit.
- Builds start from the weapon as `additem` gives it: fitted with its default parts and a loaded magazine.
  These parts are marked *comes with the weapon* and are not in the command.
- Magazines (how many in total, loaded with the chosen ammo when the game has that variant, e.g. x300 for the
  AR-15 magazines) and extra loose rounds.
- **COPY COMMAND** copies `additem ... | additem ...` with the names of the game's vendor table, which often
  differ from the item names (`MP5_Picatinny_Rail`, `545x39_7N22`, `AS_VAL`...).
- Save, duplicate and delete your builds (`%APPDATA%\IRR Companion\weapons.json`).
- Game icons of the weapons, parts and ammo; the game's grey silhouette when it has no icon (AS Val, VSS,
  M14, MPX...) and in empty slots.

**Presets editor**
- The tab is now called **PRESETS**; COMPARE is a button of the editor (**◀ BACK TO PRESET** or `Esc`).
- Header with the name, a state line (closest game difficulty, settings that differ, unsaved changes) and
  **SAVE**, **COPY CODE**, **COMPARE**, **⋯** (revert, view code, duplicate, author and description, delete).
- *Only changed settings*, **MAKE MY OWN COPY** on the game difficulties, PERFORMANCE closed at the bottom.
- *Compare values to* offers **None** and no longer lists the preset being edited.

**Interface**
- **UI size** in the status bar (100 % to 200 %, on top of the Windows scaling), applied after a restart.

Your presets, favorites and hideout progress are kept. Game data: build of 2026-11-06.
Game icons and minimaps are the developers' artwork, shown for reference (see the README).
