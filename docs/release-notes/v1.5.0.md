**Automatic updates**: the app now tells you when a new version is out and updates itself in one click.

**Updates**
- At startup the app checks GitHub for a newer release (in the background, it does not slow the start).
- If there is one, a blinking **UPDATE AVAILABLE** button shows up next to the tabs.
- Click it: the app downloads the new exe (progress on the button), checks it against the SHA-256 published by
  GitHub, closes (it asks about unsaved changes first), replaces the exe and starts the new version.
- Right-click the button: **What's new** (the release notes) or **Skip this version**.
- The version number at the bottom right: check for updates now, turn the check at startup on or off, release page.
- If the exe is in a folder you cannot write to (*Program Files*), the button opens the download page instead.

This version must be downloaded by hand one last time: the updates after it install themselves.

Your presets, favorites, weapon builds, hideout progress and settings are kept. Game data: version 1.4.0.1
(2026-11-06). Game icons and minimaps are the developers' artwork, shown for reference (see the README).
