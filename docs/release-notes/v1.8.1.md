**Start a mission from a list**: when a story mission does not come, start it with one command.

**COMMANDS** (app and web)
- *Start mission* (`irr.Mission.Start`) now offers the 54 missions the game accepts, read from the game's debug
  mission list: the 26 story missions numbered in story order (e.g. *12. Opening Eyes - Part 2*), the
  reconnaissance missions and the FANG assignments. You can still type another name.
- Names with spaces are put in quotes: `irr.Mission.Start "Opening Eyes - Part 2"`.

If you have v1.5.0 or later, the **UPDATE AVAILABLE** button next to the tabs installs this version in one click.

Your presets, favorites, weapon builds, hideout progress and settings are kept. Game data: version 1.4.0.1
(2026-11-06). Game icons and minimaps are the developers' artwork, shown for reference (see the README).
